Boss Behavior Timeline (12 seconds per cycle)
==============================================

Phase 1: SHOOT (4 seconds / 240 frames)
┌────────────────────────────────────────┐
│ ● Move like player (edge bouncing)     │
│ ● Shoot bullets (health-scaled rate)   │
│   - Full health: 2x/sec (30 frames)    │
│   - Low health:  6x/sec (10 frames)    │
│   - 30% chance for charged bullets     │
└────────────────────────────────────────┘
                   ↓
Phase 2: DROP (4 seconds / 240 frames)
┌────────────────────────────────────────┐
│ ● Move like player (edge bouncing)     │
│ ● Drop enemies (health-scaled rate)    │
│   - Full health: 1x/sec (60 frames)    │
│   - Low health:  3x/sec (20 frames)    │
│   - Drops random p/k enemies           │
└────────────────────────────────────────┘
                   ↓
Phase 3: MOVE ONLY (4 seconds / 240 frames)
┌────────────────────────────────────────┐
│ ● Move like player (edge bouncing)     │
│ ● No shooting or dropping              │
│ ● "Breather" phase for player          │
└────────────────────────────────────────┘
                   ↓
                REPEAT
                   ↑
                   └──────────────────────┘

Movement Behavior (all phases):
- Horizontal velocity based on boss.config.speed
- Bounces off screen edges (reverses direction)
- Mirrors player movement pattern
- Constrained to x: [8, 119], y: [28, 72]

Health-Based Difficulty Scaling:
┌─────────────┬──────────────┬──────────────┐
│ Boss Health │ Shoot Rate   │ Drop Rate    │
├─────────────┼──────────────┼──────────────┤
│ 100%        │ 30 frames    │ 60 frames    │
│ 75%         │ 25 frames    │ 50 frames    │
│ 50%         │ 20 frames    │ 40 frames    │
│ 25%         │ 15 frames    │ 30 frames    │
│ 0%          │ 10 frames    │ 20 frames    │
└─────────────┴──────────────┴──────────────┘

DSL Breakdown:
"(move_player_like,shoot_player_like:240,stop_shooting,move_player_like,drop_enemies:240,stop_dropping,move_player_like:240)*9999"

Parsed as:
1. move_player_like       - Start continuous movement
2. shoot_player_like:240  - Shoot for 240 frames (movement continues)
3. stop_shooting          - Stop shooting
4. move_player_like       - Ensure movement continues
5. drop_enemies:240       - Drop enemies for 240 frames (movement continues)
6. stop_dropping          - Stop dropping
7. move_player_like:240   - Move only for 240 frames
8. *9999                  - Repeat cycle 9999 times
