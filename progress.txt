#2: Scaffolded obsi.html by copying spaceInvaders.html and stripping out barriers, UFO, multi-input switching, keyboard directional movement, and marching sounds. Wired up engineInit callbacks with blank playfield rendering at 960x540 with black background and HUD placeholders for score, lives, and level. Player renders but has no input handling yet.

#3: Implemented auto-movement and basic shooting. Player ship auto-moves horizontally at fixed speed, bouncing off left and right edges. Auto-shoots bullets upward every 20 frames. Bullets travel upward and destroy when off-screen. No keyboard/mouse input affects movement.

#4: Implemented full Player FSM with 6 states (moving, charging, charged, speed_burst, burnout, pacifist) and Magic Combo input system. Mouse click controls: tap reverses direction, hold to charge (slows to 0.2x speed), charged state at 1s (resumes 1x speed), release charged for charged shot + speed burst (4x speed), hold too long triggers burnout (2x speed, locked input). Uses LittleJS Timer class for timed transitions and velocity acceleration/deceleration.

#5: Implemented weapon temperature system. Auto-shooting raises temperature 10 per shot, passive cooling 0.6 per frame. Warm zone (40-70 temp) gives fire-rate bonus. Overheat at 100+ temp triggers burnout state automatically. Added HUD temperature bar with color gradient: blue=cool, orange=warm, red=overheat.

#6: Implemented Wave FSM with transition/combat/boss_defeated/cycle_transition states. Wired Wave FSM to Player FSM: wave start puts player in pre_entry, immediately transitions to pacifist/moving. Wave clear triggers player exiting. Wave counter increments, boss waves every 10th wave (10, 20, 30...). Added wave number to HUD with boss label.

#7: Implemented Shooter enemy, ENEMY_CONFIGS object, and difficulty scaling. Created calcDifficulty(waveN) function for wave-based scaling. Spawns 5x11 grid of shooters that move side-to-side, drop on wall, speed up as count falls. Shooters fire downward from column lowest alive. Bullet-enemy collision detection with score awarding. Formation speed scales with difficulty.

#8: Implemented Diver enemy with diving behavior. Divers sit in formation (odd rows), periodically break out and dive toward player position. Return to original formation slot after reaching player Y level. Diver-player collision causes life loss. Dive chance and speed scale with difficulty. Mixed Diver (cyan) and Shooter (red) grid formation.

#9: Implemented Reflector and Absorber enemies. Reflector (yellow) reflects player bullets downward as enemy projectiles and takes 3 hits to destroy. Absorber (dark blue) absorbs bullets up to maxStored, displays count, spits in spread pattern on maxStored or spitDelay. Spawning: row 0=shooter, 1=diver, 2=reflector, 3=absorber, 4=shooter. Updated scoring to reflect each enemy type value.

#10: Implemented Treasure mini-boss. Spawns every 30s during combat, bounces diagonally around screen with pool-ball physics, high health (50), awards large score bonus (500) on defeat. Only one treasure active at a time, does not count toward wave clear. Distinctive gold sprite.

#11: Implemented Boss wave (v1 stub). Every 10th wave spawns single Boss instead of grid. Boss moves side-to-side, fires 3-bullet spread downward. Health and fire rate scale with cycle number (every 10 waves). Boss defeat triggers celebration → cycle_transition → next cycle. Difficulty increases each cycle. Game loops indefinitely through 10-wave cycles.

#12: Added Space bar keyboard alias for Magic Combo input. Extracted three helper functions (btnPressed, btnReleased, btnDown) that check both mouse (left-click) and keyboard (Space) input. Updated Player FSM methods (updateMoving, updateCharging, updateCharged) to use helpers instead of raw mouse calls. Space bar now triggers charge on press, reverses direction on tap, fires charged shot on release, and triggers burnout on held-too-long, with mouse left-click behavior unchanged.
