# 2026-05-24: prototype-phase-constraints

Starting the project. Decided to keep prototypes as single HTML files — no bundler, no external assets, just LittleJS and a browser. Feels limiting but that's the point: I want to iterate fast without setting up infrastructure. The constraints are borrowed from the LittleJS-AI submodule's own guidelines. Once I know what the game actually is, I'll relax them.
