# Weapon and Stat Upgrade Implementations
Status: completed

## What to build
Implement the actual logic for Stat Buffs (Speed Boost, Fire Rate, Magnet) and Weapons (Spread Shot, Orbital). Hook these implementations into the Level Up menu so they are randomly offered and properly applied when selected by the human player.

## Acceptance criteria
- [x] Speed Boost increases AI movement speed.
- [x] Fire Rate reduces human weapon cooldown.
- [x] Magnet increases EXP gem pickup radius.
- [x] Spread Shot causes the player's weapon to fire 3 bullets in an arc.
- [x] Orbital spawns a permanent orbiting, damaging spark around the player.
- [x] Upgrades are randomly drawn and applied via the Level Up menu.
