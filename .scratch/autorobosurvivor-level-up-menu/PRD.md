# Level Up Menu & Pause State
Status: completed

## What to build
Implement a game state that pauses the logic when `playerExp >= playerMaxExp`. Display an HTML or canvas-based menu offering 3 placeholder upgrade options. Clicking an upgrade applies it (for now, simply logs or does nothing), increments `playerLevel`, scales up `playerMaxExp`, resets `playerExp`, and resumes the game.

## Acceptance criteria
- [x] Game pauses when EXP threshold is met.
- [x] Menu appears showing 3 options.
- [x] Selecting an option closes the menu and resumes the game.
- [x] Level increments and max EXP scales up for the next level.
