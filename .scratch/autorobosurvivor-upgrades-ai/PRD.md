# AI Driver Behavior Upgrades
Status: completed

## What to build
Implement logic for AI Driver Tweaks: Greedy Driver (heavily weights towards EXP gems), Hero Driver (heavily weights towards humans), and Aggressive Driver (decreases avoidance weight to stay at an optimal offensive distance from enemies). Hook these into the Level Up menu.

## Acceptance criteria
- [x] Greedy Driver upgrade modifies steering to aggressively pursue EXP gems.
- [x] Hero Driver upgrade modifies steering to aggressively pursue humans.
- [x] Aggressive Driver upgrade modifies steering to maintain offensive distance from enemies.
- [x] Upgrades are randomly drawn and applied via the Level Up menu.
